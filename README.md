# Sinefolis

## About
Sinefolis adalah sebuah proyek pengembangan antarmuka (User Interface) berbasis web. Proyek ini dibuat sebagai implementasi dari perancangan interaksi manusia dan komputer (HCI), yang berfokus pada pengalaman pengguna (User Experience) yang baik, responsif, dan interaktif.

## Teknologi yang Digunakan
- **HTML5:** Untuk kerangka dan struktur utama website.
- **CSS3:** Untuk tata letak, desain, dan animasi visual.
- **JavaScript:** Untuk menambahkan interaktivitas pada halaman web.
- **Figma:** Untuk pembuatan *wireframe* dan desain purwarupa (prototipe) awal UI/UX.

## Struktur Folder dan File
- `index.html` — File utama yang berisi struktur halaman web Sinefolis.
- `style.css` — File khusus gaya (styling) untuk mempercantik tampilan halaman.
- `script.js` — File logika pemrograman untuk interaksi tombol dan elemen dinamis lainnya.
- `HCI.fig` — Berkas desain mentah dari Figma yang menjadi acuan tampilan website.
- `Dokumentasi.pdf` — Laporan lengkap mengenai analisis kebutuhan, perancangan, dan dokumentasi proyek.
- `gambar/` — Direktori (folder) yang menyimpan seluruh aset gambar, logo, dan ikon pendukung.

## Cara Menjalankan Proyek
Proyek ini berjalan sepenuhnya di sisi klien (Client-side) tanpa memerlukan instalasi server khusus.
1. Unduh (Clone) repositori ini ke komputer Anda.
2. Buka folder proyek tersebut.
3. Klik dua kali pada file `index.html` untuk membukanya secara langsung menggunakan browser (Chrome, Edge, Safari, atau Firefox).
4. (Opsional) Jika menggunakan VS Code, Anda bisa menginstal ekstensi **Live Server** untuk melihat perubahan kode secara langsung.
